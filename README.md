**HindSight: A Securities Backtesting Tool**

HindSight is a web-based financial backtesting application designed to evaluate a moving average (MA50) trend-following strategy
against both a buy & hold strategy as well as using an S&P 500 (SPY) benchmark

**Key Features:**
* Calculates key performance metrics: Annualized Return, Alpha, Beta, Sharpe Ratio, Maximum Drawdown, etc.
* Uses Plotly to render dynamic equity curves to create a visual comparison of the built-in MA50 strategy, the asset's buy & hold
  performance and a market benchmark, using SPY.
* Frontend: HTML5, Tailwind CSS, Plotly,js
* Backend: Python, FastAPI

**Requirements:**
* Python 3.9+
* pip
